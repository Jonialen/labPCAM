# Entregables del Laboratorio

Cada estudiante deberá entregar **4 archivos**:

1. `explicacion_pcam.pdf`
   * Explicar brevemente cómo aplicó **Partition**, **Communication**, **Agglomeration** y **Mapping**.
   * Justificar las decisiones principales de OpenMP.

2. `nbody_secuencial.c`
   * Versión funcional sin paralelismo.

3. `nbody_paralelo.c`
   * Versión con OpenMP.
   * Código comentado y sin condiciones de carrera.

4. `evidencia.pdf`
   * Capturas de compilación y ejecución.
   * Mostrar tiempos, número de threads y al menos una comparación de rendimiento.

> **Entrega:** Por Canvas.
